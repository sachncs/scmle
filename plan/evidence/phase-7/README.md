# Phase 7 evidence artifacts

Generated by `scripts/make_phase7_evidence.py` (run offline, about one
minute). Nothing in these folders was written by hand; re-running the script
replaces them. The oracle comparison table is `docs/ORACLES.md`, generated by
`python -m benchmarks.qualification.oracle_table`.

| Folder | What it is | What it is not |
|---|---|---|
| `signed-sample-run/` | The small artifacts of a charter run on the scikit-learn breast-cancer table (public, bundled with scikit-learn): signed charter, split manifest, hypothesis ledger, negative control, confirmed claims, custody log with MACs, and `verification.json` from the library's own verifiers | The charter is signed with a **published demonstration key** (`scmle-phase7-demonstration-key-not-secret`), so the signature shows tamper evidence only. The roadmap asked for a key whose holder is not the author: that is not met. Models, profiles and the other run files are not kept |
| `access-attempt-log/` | The custody log (hash chain and MACs) of five scripted attempts on a real vault process, and `attempts.json` with what each returned: a guessed token, the right token without the binding, the right token with another ledger state, the correct release, and a second release | The attacker is the generator script. It is not the independent red team (F7 W2) and does not show that no other attack works |
| `split-manifests/` | The run's manifest, and the manifests of the grouped and temporal fixtures whose hashes `tests/unit/test_custody_golden.py` pins | The v2 manifest holds ids, folds and Merkle roots over row content, not row values |

To check the sample run: `tests/unit/test_phase7_evidence.py` re-verifies every
file above with the demonstration key; the same verifiers run
inside the script.
