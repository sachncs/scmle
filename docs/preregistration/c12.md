# C12 Docs tell the truth: pre-registration

Registered 2026-11-17. Shared rules: [README.md](README.md).

## Criterion

Every guarantee in the docs and site linked to an enforcing test; every
snippet and command runs in a fresh process; a planted false statement
fails CI.

## Population and data

- Guarantees: units of `README.md`, `docs/*.md` and the site, found as
  `benchmarks/evidence/guarantees.py` finds them (its `WORDS`, skipping
  code, comments and headings).
- Snippets: every fenced code block and command in the same files.
- Planted statements: false statements written into a copy of the docs
  (a changed default, a reversed refusal, a wrong limit).

## Split

Validation. The planted false statements are written by someone other
than the builder and sealed before CI runs on them; the ones the builder
uses to test the checker are development. Guarantees and snippets are the
whole population at the commit scored.

## Statistic

Guarantees linked over guarantees; snippets that run over snippets;
planted statements caught over planted statements; in an audit of a
random sample of links, links whose test would fail if the guarantee were
false.

## Decision rule

Policy, all-or-nothing: every guarantee linked, every snippet runs, every
planted statement fails CI. The link audit: zero non-enforcing links in
the sample, which with 59 links bounds the non-enforcing share at 0.05
(`Ceiling(0.05)` at `alpha`). `acceptance.toml` has no variable for the
audit; until one is added, its result is reported and does not decide.

## Sample size

Not sampled for linkage, snippets or planted statements (every one, and
at least 10 planted statements, one per scanned doc that holds a
guarantee). Link audit: 59 links, the minimum of a 0.05 ceiling at
`alpha` = 0.05, drawn with a seed fixed in the commit that adds it.

## What counts as a failure

An unlinked guarantee; a link to a test path that does not exist; a
snippet that fails in a fresh process; a planted statement that passes
CI; an audited link whose test does not check the guarantee.

## Grader

CI from the committed module; the link audit and the planted statements
by the validator.

## Where the current module differs

- `guarantees.py` checks linkage only: a link names one specific test
  (cited by its file and function, or a test function that names the
  statement's lines), but nothing runs that test against a false version
  of the statement, so a link is not proof that the test enforces the
  guarantee. Snippets and planted statements: the last two items.
- The scorecard decides the claim on all three clauses. Linkage and the
  snippets are measured; planted statements are not, so the claim cannot
  pass on linkage and snippets alone.
- Its 241/241 result was computed before this registration.
- `snippets.py` measures the snippets: every code block of every scanned
  page, each declaring its language, run as a reader would follow the page
  (a fresh empty folder per page, a fresh process per block, the working
  directory and exported variables carried between shell blocks), with a
  time cap of twice the largest documented `--budget`. Text blocks are
  shown output; they are counted and not compared with what the commands
  print. A PowerShell block is skipped where `pwsh` is not installed, and a
  skip counts against the clause. A block marked `synopsis` is a usage
  pattern with placeholders (`<sha>`, `[--json]`, `...`), not a command:
  it is not run, and it is counted and listed apart from the snippets. A
  synopsis without a placeholder fails, so a command cannot be hidden as
  one.
- Planted statements: `tests/benchmarks/test_evidence_planted.py` plants
  the builder's development set (a changed default, a reversed refusal and
  a wrong limit, one in every doc that holds a guarantee). A new false
  statement is caught as an unlinked guarantee. An edit to a linked
  statement makes the stored result stale, which fails CI's `--check`, but
  once re-measured it is caught only if the linked test reads the
  statement. CI fails on stale evidence, not on an unlinked guarantee, and
  there is no link audit yet.
