# C9 Secure, private, trustworthy supply chain: pre-registration

Registered 2026-11-17. Shared rules: [README.md](README.md).

## Criterion

No unauthenticated deserialisation path; no raw rows, raw category
strings or secrets in artifacts by default; a "forget" operation that
removes or proves absent a person's rows; OpenSSF Scorecard at least
`openssf_score_min`; SLSA provenance, signed releases, tag protection, no
known high vulnerability.

## Population and data

- Code: every deserialisation call site in `scmle/`, found by a static
  check.
- Artifacts: every file of a bundle, run folder and log produced from a
  PII-planted corpus (tables with planted names, identifiers, free text,
  rare category strings and secrets).
- Forget: runs on the same corpus, then a forget request for planted
  persons.
- Supply chain: the repository and its release workflow at the commit
  scored.

## Split

Validation. The PII-planted corpus is split by table into development and
validation by a seeded hash; the validation tables and their planted
values are sealed before scoring. The static checks and the supply-chain
checks have no data to split.

## Statistic

Counts: unauthenticated deserialisation sites; planted values found in
any artifact; forget requests that leave a row or cannot prove absence;
the OpenSSF Scorecard total; known high vulnerabilities.

## Decision rule

Policy, all-or-nothing: zero for every count, Scorecard at least
`openssf_score_min` = 8, provenance, signatures and tag protection
present. No `alpha`.

## Sample size

Not a rate: every call site, every artifact file, every planted value of
the validation corpus (at least one table per data kind in scope), every
release.

## What counts as a failure

Any planted value in an artifact, in any form (raw, hashed with a known
salt, or in a column header); any deserialisation of untrusted bytes
without authentication; any forget that leaves a trace; a Scorecard below
8; a known high vulnerability in the lock file.

## Grader

Third-party tools (OpenSSF Scorecard, a vulnerability scanner), and the
static and corpus checks committed before the validation corpus is read;
the planted values are chosen by someone other than the builder.

## Where the current module differs

There is no evidence module. `benchmarks/scorecard.py` reports the row as
"not measured".
