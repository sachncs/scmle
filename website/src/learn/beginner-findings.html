What went wrong, or was confusing, when the author followed the beginner path on the Titanic table that ships in the repository (tests/fixtures/ titanic_extract.csv), using the real command line and the Python API. Each item says what happened, what was done, and what is left.

How this was gathered: the whole path was run once in the repository's own environment, then re-run from a fresh clone, a fresh virtual environment and a fresh working folder, typing only what START_HERE.md says. The author is not a beginner, so the second pass is a simulation. A real beginner has not tested these pages.

Things that worked on the first try

  • Install from a fresh clone with pip install . (about 20 seconds with cached downloads) and the scmle command appeared.
  • plan, the leakage block (exit 2), the real run, predict, signed bundle refusals, serve with its readiness endpoints, package, the registry approval and the rollback, the monitor and the loop commands all behaved as the code and docs say.
  • The command-line run and the Python run, with the same seed and data, gave identical scores on the author's first machine.

What I could not verify

  • A real beginner. Everything above is from the author's own pass.
  • A build of the container from scmle package (no Docker was run).
  • A release against a live deployment. Only the local steps were run.
  • scmle frame (the plain-request drafting) and scmle ingest (raw tables) were not exercised.
  • A full charter run with a leakage attestation. The file format is taken from the source and the repository's own test.
  • Windows. All commands were run on macOS.
